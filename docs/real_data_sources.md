- 原始数据集标识：`0162a542-4f2e-4fe2-ad5d-8f6ed2344056`

- 下载日期：2026-09-22
- 本项目本地文件：`data/raw/usaid_supply_chain/usaid_supply_chain_shipments.csv`
- 本地文件 SHA-256：`c9ca9530539e7dbf37b377f3fcd383e1faa81c8e41c707e280b20a485508a537`

- 核心字段：目的国、供应商、制造地点、运输方式、计划/实际交付日期、数量、货值、运费、保险费。

数据门户当前无法建立连接，本地 CSV 从公开 GitHub 镜像取得，并通过字段、行数和原始数据集标识进行来源核对。项目在看板和报告中保留该限制，不把镜像描述成当前的官方直连。

### 重要限制

- `Freight Cost (USD)` 不全是数值，还包含“Freight Included in Commodity Cost”、“Invoiced Separately”和引用其他单据等文本状态。只有 60.0% 的明细行能直接转为数值运费。
- 已知运费不等于完整物流总成本；文本状态不能当作 0。
- USAID 原始说明提醒用户考虑业务背景，不宜用该数据对特定产品/国家的运输成本或交付周期做精确因果结论。

## 4. 派生复核队列与能耗成本情景

以下内容是本项目对原始数据的分析产物或模型输入，不是新增的真实企业数据：

- **物流复核队列**：由 USAID 原始发运行规则筛选，逐行保留可回查的发运标识、货值、延期、运费状态、触发规则、优先级、建议复核部门和待办状态。触发条件为行货值不低于全体 P95、延期不少于30天、数值运费不低于数值运费 P95，或运费状态不是 `numeric_amount`。P1 为延期≥30天且同时高货值/高已知运费、延期≥60天或货值≥P99；P2 为其余高货值、长延期和高运费单项；P3 为仅有运费完整性问题。缺失/文本运费不会按 0 计算。队列表示待检查记录，不代表已确认异常、供应商责任或实际损失。
- **建议复核部门**：延期记录建议物流/计划核查；非数值运费建议物流/应付/数据治理核查；高已知运费建议采购/物流核查；高货值建议采购/供应商管理核查。此为按触发类型配置的建议路由，项目没有企业实际组织架构，须按使用方职责调整。
- **线路分析**：按运输方式 × 目的国 × 制造地点聚合发运行数、货值、延期率、平均延期、可数值运费和运费数值覆盖率。组合样本量及历史数据结构可能不同，分组差异不能单独用于因果结论。
- **能耗费率情景**：UCI 未提供电费合同或当地分时电价，因此费率为可编辑的作品集假设，不能引用为当地真实执行政策。默认峰/平/谷电价为 **0.90 / 0.60 / 0.30 元/kWh**，需量单价为 **40 元/kW·月**；峰段定义为 **09:00–16:59**，平段为 **07:00–08:59、17:00–21:59**，谷段为 **22:00–06:59**。工作日与周末暂用同一组时段和费率。
- **工作日/周末与负荷操作**：负荷转移按守恒处理，将峰段电量按设定比例从峰段移出并加到谷段，不改变总电量；削峰比例只作用于月峰值需量，不额外减少 kWh。基准、轻度和强化情景分别使用转移/削峰比例 **0%/0%、5%/3%、10%/8%**。这些比例不是现场实施结果。
- **需量近似**：UCI `Usage_kWh` 是15分钟间隔用电量；用 `kW ≈ kWh × 4` 将单间隔电量换成平均功率，逐月取观测峰值近似当月最大需量，再乘以假设需量单价。该值不一定等于电表/账单采用的最大需量、合同需量或计费周期，且时间戳的区间起止约定需要业务核实。
- **模型结果命名**：报告与看板展示“模型情景成本”和“模型差额”。差额只是不同参数下的数学比较，不可称为真实电费、实际节省、降本成果或经审计财务结果。

若将模型用于真实经营决策，应先取得适用地区的电价合同/账单、需量计费口径、班次与工作日历、设备运行记录和产量，再校准时段规则与参数。
