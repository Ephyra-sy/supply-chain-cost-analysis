# 制造供应链成本管控与经营分析｜交付说明

## 直接查看

- `制造成本管控看板.html`：交互式看板，展示发运货值、准时率、已知运费覆盖率、物流线路、逐单复核队列、钢厂能耗和参数化成本情景。
- `制造成本分析报告.html`：管理分析报告，包含运输方式 × 目的国 × 制造地点切片、可回指原始发运 ID 的物流异常待办、运费状态、工作日/周末峰平谷用电、能耗成本情景和敏感性分析。

两份文件均为离线 HTML，可直接双击打开，不需要安装 Python、Node.js 或连接数据库。

## 数据边界

- 主看板和主报告只使用 USAID 真实公开发运数据和 UCI 真实钢厂能耗数据。
- USAID 原始门户当前不可访问，项目使用公开镜像中的同一数据文件，并保留原始数据集标识和文件哈希。
- 运费只有 60.0% 明细可直接数值化，所以“已知运费”不是完整物流总成本。
- UCI 数据没有验证电价和产量，项目不伪造金额化节约成果。
- USAID 与 UCI 数据来自不同机构和时期，不合并为某家企业的整体经营结论。
- 物流待办由透明规则筛选，优先级用于安排复核；这不等于确认了异常原因或责任。
- 当前规则队列含 4,835 条记录（P1 202、P2 751、P3 3,882），每条可用原始发运ID回查；这是需要人工核实的筛查结果。
- 能耗费用由可编辑费率、需量单价及负荷转移/削峰比例计算。峰段暂按09:00–16:59、平段按07:00–08:59和17:00–21:59、谷段按22:00–06:59；工作日和周末采用同一组时段。15分钟 kWh 乘4近似为 kW，每月最大间隔功率用于需量费估算。所有输入为作品集情景假设，金额和差额不能称作真实账单成本或实际节省。
- 默认参数下，基准/轻度/强化模型成本分别约 99.7/97.2/94.1 万元；仅反映情景假设变化，不是实际节约额。

## 项目能力覆盖

- 真实公开数据获取、来源记录和文件哈希
- 日期标准化、混合字段清洗、缺失与重复检查
- 采购物流货值、准时率、延迟和运费覆盖分析
- 制造能耗月度、分时和负荷结构分析
- 管理层报告、可视化看板和数据口径披露
- 原始发运记录回查、规则触发证据、优先级及待办状态
- 峰谷电价、需量费、负荷转移和削峰假设下的成本区间/敏感性分析
