# 数据质量检查报告

## 结论

两份数据都可以支撑作品集级的描述性分析。UCI 能耗数据完整性高；USAID 发运数据的日期、货值和分类字段可用，但运费与重量字段同时包含数值和文本状态，不能直接把空值/文本当作 0。

| --- | --- | ---: | --- |
| USAID | 行数 | 10,324 | 通过 |

| UCI | 时间戳解析率 | 100.0% | 通过 |
| UCI | 核心字段缺失 | 0 | 通过 |

## 处理决策

1. 准时交付率使用“实际交付日 ≤ 计划交付日”的明细行占比。
2. 运费只对可数值化的记录求和，并与 60.0% 覆盖率同时展示。
3. 运输方式缺失的 360 行标记为“未记录”，不丢弃。
4. 能耗数据按月、小时、负荷类型和工作日/周末汇总。
5. 没有可验证电价时，不将 kWh 人为转换为货币成本。
