# 供应链成本分析

面向制造费用、项目成本、库存稽核和采购降本岗位的求职作品集项目。

## 数据边界

- 制造、采购、工单和库存数据来自 Microsoft AdventureWorks 公开教学样例。
- 预算、费用台账、盘点、项目成本和浪费稽核数据由固定随机种子生成，用于模拟完整的成本管控流程。
- 所有报告和看板必须区分公开样例观测值与仿真场景数据，不将其表述为真实企业内部绩效。

## 第一阶段交付

1. 制造成本管控可视化看板。
2. 管理层成本与风险分析报告。
3. 可复现的数据下载、仿真、指标计算和验证脚本。

## 后续交付

- Excel 成本核算与预算分析模型。
- 月度经营分析汇报材料。
- 简历描述和面试讲解手册。

## 目录

```text

```
